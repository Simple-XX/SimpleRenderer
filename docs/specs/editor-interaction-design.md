**日期**: 2026-03-18
**状态**: 草案

**前置**: `docs/specs/2026-03-18-scene-editing-design.md`（场景编辑架构）

## 1. 设计目标

### 1.1 核心目标

> **让用户在视口中直接操作 3D 场景，像使用 Unity/Unreal 一样自然。**

| 目标 | 度量标准 |
|------|----------|
| **直觉性** | 新用户不看文档可以完成：加载模型 → 选中 → 移动 → 保存 |
| **高效性** | 熟练用户全键盘操作，鼠标与键盘自然切换 |
| **一致性** | 快捷键与 Unity/Blender 对齐，降低学习成本 |
| **反馈性** | 每个操作有即时视觉反馈，错误有明确提示 |

### 1.2 设计原则

1. **视口优先** — 90% 的操作应该可以在视口内完成，面板是辅助
2. **右键上下文** — 任何可交互区域右键都应该有上下文菜单
3. **渐进暴露** — 基础功能显眼，高级功能在菜单/面板中
4. **键盘加速** — 每个常用操作都有快捷键，且可发现（tooltip 显示快捷键）
5. **状态可见** — 当前工具、选中实体、修改状态，随时可见

### 1.3 参考基准

| 参考 | 借鉴内容 |
|------|----------|
| **Unity** | 工具栏布局（左侧变换工具 + 中部播放 + 右侧布局）、Inspector 面板 |
| **Unreal** | 视口相机操作（右键+WASD 飞行、Alt+左键 环绕）、Outliner 场景树 |
| **Godot** | 紧凑的属性面板、场景树拖拽排序 |
| **Blender** | 高效的快捷键系统、G/R/S 即时变换 |

## 4. 视口交互设计

### 4.1 视口层次结构

视口由 4 个渲染层叠加组成（从下到上）：

```
Layer 4: Gizmo 覆盖层（egui 绘制，始终在最上层）
Layer 3: 选中高亮轮廓（选中实体的橙色轮廓）
Layer 2: 调试覆盖层（网格、坐标轴、包围盒、法线）
Layer 1: 3D 渲染画面（软件渲染器输出）
```

### 4.2 网格参考面 (Grid)

- **默认显示** XZ 平面网格（Y-up 世界坐标）
- **密度**：主网格线 1 单位间距（白色 10% 透明度），子网格线 0.1 单位（白色 3% 透明度）
- **范围**：50×50 单位，随相机位置滑动
- **快捷键**：`G` 切换网格显示/隐藏
- **实现**：在软件渲染器中增加 Grid 渲染 pass，或用 egui 线段绘制

### 4.3 坐标轴指示器 (Axis Indicator)

视口右下角显示一个小的 XYZ 坐标轴指示器：
```
      Y (绿)
      │
      │
      └──── X (红)
     /
    Z (蓝)
```

- 固定在视口右下角，大小约 60×60 像素
- 随相机旋转实时更新方向
- 点击某个轴的标签，可以切换到正交视图（正面/侧面/顶部）
- 实现：用 egui 的 `Painter` 在视口覆盖层绘制

### 4.4 视口内信息覆盖

视口左上角显示上下文信息：
```
┌─────────────────────────┐
│ 移动工具 (W)            │  ← 当前工具
│ 选中: Teapot            │  ← 选中实体
│ 位置: (1.2, 0.0, -3.5) │  ← 实体位置
└─────────────────────────┘
```

半透明背景，不遮挡视口主要区域。

## 5. 相机系统设计

### 5.1 操作模式汇总

| 输入 | 动作 | 说明 |
|------|------|------|
| **右键 + 移动** | 环视 (Look Around) | FPS 风格旋转视角，保持位置 |
| **右键 + WASD** | 飞行 (Fly) | 保持右键按住，WASD 移动 |
| **右键 + Q/E** | 升降 (Up/Down) | Q 下降，E 上升 |
| **Alt + 左键拖拽** | 环绕 (Orbit) | 以 Pivot 点为轴心旋转 |
| **Alt + 右键拖拽** | 推拉 (Dolly) | 沿视线方向前后移动 |
| **Alt + 中键拖拽** | 平移 (Pan) | 垂直于视线平移 |
| **滚轮** | 缩放 (Zoom) | 前后移动相机 |
| **Shift + 滚轮** | 快速缩放 | 5× 速度缩放 |
| **F** | 聚焦 (Focus) | 相机飞向选中实体 |
| **数字键 1** | 前视图 | 切换到正交 +Z 视角 |
| **数字键 3** | 右视图 | 切换到正交 +X 视角 |
| **数字键 7** | 顶视图 | 切换到正交 -Y 视角 |
| **数字键 5** | 透视/正交切换 | 在透视和正交投影间切换 |

### 5.2 Orbit 模式详解

Orbit（环绕）是 3D 编辑器中最常用的相机操作：

**轴心点 (Pivot)** 确定规则：
1. 如果有选中实体 → 选中实体的 Transform.translation
2. 如果没有选中实体 → 世界原点 (0, 0, 0)
3. 如果上次使用了 Focus → Focus 的目标位置

**动画过渡**：
- 切换视图（数字键 1/3/7）时，相机位置/旋转 **平滑插值**（0.3 秒 ease-out）
- Focus（F 键）时，相机 **飞向** 目标位置（0.5 秒 ease-in-out）
- 普通操作（Orbit/Pan/Dolly）**无动画**，即时响应

### 5.3 飞行模式速度控制

| 操作 | 效果 |
|------|------|
| 右键 + WASD | 以当前速度移动 |
| 右键 + Shift + WASD | 3× 加速移动 |
| 右键 + 滚轮 | 实时调整飞行速度（0.5–50.0 范围） |

飞行速度在状态栏显示，方便用户感知。

### 5.4 相机状态机

```
                    ┌──────────────┐
                    │   空闲 (Idle) │◄──── 释放所有键
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
        右键按下      Alt+左键按下   Alt+中键按下
              │            │            │
              ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ 飞行/环视 │ │  环绕    │ │   平移   │
        │  (Fly)   │ │ (Orbit)  │ │  (Pan)   │
        └──────────┘ └──────────┘ └──────────┘
```

**关键约束**：相机操作只在视口 hover 时响应，避免与面板交互冲突。

## 6. 选择系统设计

### 6.1 选择方式

| 操作 | 行为 |
|------|------|
| **视口左键单击** | 选中鼠标下方的实体（射线拾取） |
| **视口左键点空白** | 取消选择 |
| **场景树左键单击** | 选中实体（双向同步） |
| **Ctrl + 左键** | 多选 — 追加/移除选中（未来扩展） |
| **Delete / Backspace** | 删除选中实体 |
| **Ctrl + D** | 复制选中实体 |
| **Escape** | 取消当前选择 / 取消当前操作 |

### 6.2 射线拾取算法

1. 获取鼠标在视口中的像素坐标 `(mx, my)`
2. 转换为视口 NDC：`nx = (mx / viewport_w) * 2 - 1`, `ny = 1 - (my / viewport_h) * 2`
3. 反投影到世界空间：
   ```
   inv_vp = (projection * view)^-1
   near = inv_vp * (nx, ny, -1, 1)  → 除以 w
   far  = inv_vp * (nx, ny,  1, 1)  → 除以 w
   ray = Ray { origin: camera_pos, direction: normalize(far - near) }
   ```
4. 对所有实体的 AABB 做 `Ray::intersects_aabb`
5. 选择 t 值最小的（最近的）命中实体

### 6.3 选中状态表示

**视觉反馈**：
- 选中实体在视口中显示 **橙色轮廓**（outline / silhouette）
- 场景树中选中行高亮（蓝色背景）
- 属性面板显示该实体的组件
- 状态栏显示选中实体名称 + 位置

**数据模型**：
```rust
pub struct SelectionState {
    /// 当前选中的实体
    pub selected: Option<Entity>,
    /// 上一次选中的实体（用于双击等操作）
    pub previous: Option<Entity>,
}
```

### 6.4 选择与面板联动

```
用户点击视口中的物体
        │
        ▼
SelectionState.selected = entity
        │
        ├──► 场景树: 高亮对应行，自动滚动到可见
        ├──► 属性面板: 刷新，显示该实体的所有组件
        ├──► 视口: 显示 Gizmo（如果当前工具是 W/E/R）
        └──► 状态栏: 更新 "选中: {实体名}"
```

## 7. Gizmo 系统设计

### 7.1 Gizmo 外观

**移动 Gizmo (W)**:
```
          Y (绿色箭头)
          │
          │
          ├──── X (红色箭头)
         /
        Z (蓝色箭头)
```
- 3 个方向箭头 + 3 个面板（XY/XZ/YZ 平面移动）
- 箭头长度固定屏幕大小（不随缩放变化）

**旋转 Gizmo (E)**:
- 3 个颜色圆环（红/绿/蓝 = X/Y/Z 轴旋转）
- 外围白色圆环 = 沿视线轴旋转

**缩放 Gizmo (R)**:
- 3 个方向轴线 + 端部方块
- 中心方块 = 等比缩放

### 7.2 Gizmo 交互规则

| 操作 | 行为 |
|------|------|
| 鼠标 hover 轴 | 该轴高亮（变亮/变粗） |
| 左键拖拽轴 | 沿该轴移动/旋转/缩放 |
| 拖拽中 Shift | 吸附到网格（Snap） |
| 拖拽中 Escape | 取消操作，恢复原值 |
| 拖拽完成 | 记录为一次 Command（可撤销） |

### 7.3 Snap 吸附

| 工具 | 默认 Snap 间距 | 快捷修改 |
|------|---------------|----------|
| 移动 | 0.5 单位 | 属性面板可修改 |
| 旋转 | 15° | 属性面板可修改 |
| 缩放 | 0.1 | 属性面板可修改 |

- **默认不启用吸附**
- **按住 Shift** 临时启用吸附
- **可在工具栏设为默认开启**

### 7.4 Gizmo 实现方案

使用 `egui-gizmo` crate 在 egui 画布上绘制 2D gizmo 覆盖层：

```rust
// viewport.rs 中的 gizmo 渲染
if let Some(selected) = selection.selected {
    if gizmo_mode != GizmoMode::Select {
        let gizmo = egui_gizmo::Gizmo::new("transform_gizmo")
            .view_matrix(camera.view_matrix())
            .projection_matrix(camera.projection_matrix(aspect))
            .model_matrix(entity_global_transform)
            .mode(gizmo_mode.into());

        if let Some(response) = gizmo.interact(ui) {
            // 提交 TransformCommand 到 CommandHistory
        }
    }
}
```

## 8. 场景树设计

### 8.1 布局

```
┌─ 场景树 ─────────────────────┐
│ 🔍 [搜索实体...]            │
│ ──────────────────────────── │
│ ▼ 📦 Root                   │
│   ├── 🫖 Teapot        [👁] │ ← 可见性切换
│   │   ├── 🧊 Handle         │ ← 子实体（缩进）
│   │   └── 🧊 Lid            │
│   ├── 💡 主光源         [👁] │
│   ├── 📷 编辑器相机     [👁] │
│   └── 🧊 Ground        [👁] │
│ ──────────────────────────── │
│ [+ 添加实体]                 │
└──────────────────────────────┘
```

### 8.2 交互操作

| 操作 | 行为 |
|------|------|
| **左键单击** | 选中实体（同步到视口 + 属性面板） |
| **双击名称** | 进入重命名模式（内联编辑） |
| **右键单击** | 显示上下文菜单 |
| **拖拽** | 改变父子层级关系 |
| **👁 按钮** | 切换实体可见性（不渲染但保留在场景中） |
| **▼/▶ 箭头** | 展开/折叠子实体 |
| **搜索框输入** | 过滤实体名称（模糊匹配） |

### 8.3 右键上下文菜单

```
右键菜单
├── 📦 添加空实体           (Ctrl+Shift+N)
├── 🧊 添加模型实体...      (导入文件对话框)
├── 💡 添加灯光
│   ├── 方向光 (Directional)
│   ├── 点光源 (Point)
│   └── 聚光灯 (Spot)
├── 📷 添加相机
├── ──────────────
├── 📋 复制                  (Ctrl+D)
├── ✂️ 删除                  (Delete)
├── ──────────────
├── 📝 重命名                (F2)
├── 🔍 聚焦到此实体          (F)
├── ──────────────
├── 📌 设为子实体 →          (选择父实体)
└── 📤 取消父子关系
```

### 8.4 拖拽改变层级

- 拖拽实体 A 到实体 B **上方** → A 成为 B 的兄弟节点（排在 B 前面）
- 拖拽实体 A 到实体 B **内部** → A 成为 B 的子实体
- 拖拽到根级别 → 取消 A 的父子关系
- 拖拽时显示 **蓝色插入线** 指示放置位置
- 所有拖拽操作可撤销

### 8.5 底部"添加实体"按钮

点击后弹出与右键菜单相同的添加子菜单。提供快捷入口，降低新用户发现成本。

## 9. 属性面板设计

### 9.1 布局结构

```
┌─ 属性 ─────────────────────────┐
│ 🫖 Teapot                 [🔒] │ ← 实体名称 + 锁定编辑按钮

│   缩放  [X: 1.0] [Y: 1.0] [Z: 1.0]  │
│ ────────────────────────────── │
│ ▼ 网格渲染器 (MeshRenderer)    │
│   模型: teapot.obj        [📂] │ ← 点击可换模型

### 9.2 无选择状态

```

### 9.4 DragValue 交互细节

Transform 的数值编辑是最高频的操作，需要精心设计：

| 操作 | 行为 |
|------|------|
| **左键拖拽数字** | 连续调整数值（速度 0.1/pixel） |
| **Ctrl + 左键拖拽** | 精细调整（速度 0.01/pixel） |
| **Shift + 左键拖拽** | 粗略调整（速度 1.0/pixel） |
| **左键单击** | 进入文本输入模式，可直接输入数值 |
| **右键单击** | 重置为默认值 |
| **Tab** | 跳到下一个输入框 |

## 12. 撤销/重做系统

### 12.1 可撤销操作

| 操作 | Command 类型 | 撤销行为 |
|------|-------------|----------|
| 移动/旋转/缩放实体 | `TransformCommand` | 恢复旧 Transform |
| 添加实体 | `SpawnCommand` | Despawn 该实体 |
| 删除实体 | `DespawnCommand` | 重新 Spawn（恢复所有组件） |
| 重命名实体 | `RenameCommand` | 恢复旧名称 |
| 改变父子关系 | `ReparentCommand` | 恢复旧的父子关系 |
| 修改组件属性 | `ModifyComponentCommand` | 恢复旧属性值 |
| 改变灯光参数 | `ModifyComponentCommand` | 恢复旧参数 |

### 12.2 不可撤销操作

- 相机移动（视口导航不进入历史）
- 面板折叠/展开
- 渲染设置切换（渲染模式等）
- 项目保存

### 12.3 历史栈行为

- 最大历史深度：**100 步**
- 执行新操作后 → 清空 Redo 栈
- 连续同类操作合并（如连续拖拽移动合并为一个 TransformCommand）

### 12.4 UI 反馈

状态栏右侧显示：
```
[↩️ 撤销: "移动 Teapot"] [↪️ 重做: —]
```

```

┌────────────────────────┐
│ ❌ 模型加载失败:        │

└────────────────────────┘
```

- **成功**: 绿色背景，3 秒消失
- **错误**: 红色背景，5 秒消失，可点击关闭
- **信息**: 灰色背景，3 秒消失
